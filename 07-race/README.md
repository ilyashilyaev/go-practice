# 07-race — гонка данных и три способа починки

Счётчик, который `1000` горутин увеличивают по `1000` раз. Ожидаемый итог — `1_000_000`.

## Показать гонку

```bash
go test -race -run TestRacyIsWrong -v ./07-race
```

`RacyCount` использует общий `int` без синхронизации: детектор гонок укажет на строку `count++`, а результат будет меньше миллиона — часть инкрементов теряется (`count++` = прочитать-прибавить-записать, две горутины затирают запись друг друга).

> Тест `TestRacyIsWrong` под `-race` пропускается (`t.Skip`): `RacyCount` гонит данные намеренно, иначе детектор валил бы весь прогон. Флаг `-race` виден коду через `isRaceEnabled` из `race_enabled_test.go` / `race_disabled_test.go` (делятся build-тегом `//go:build race`).

## Три исправленные версии

| Версия | Как | Когда уместна |
|---|---|---|
| `MutexCount` | `sync.Mutex` вокруг `count++` | Под защитой не один `++`, а составная операция (несколько полей, чтение+запись, условие). Универсально. |
| `AtomicCount` | `atomic.Int64.Add(1)` | Одна простая операция над числом/флагом. Самый быстрый вариант для счётчика. |
| `ChanCount` | горутины шлют `1`, один сборщик суммирует | Когда данными владеет один «хозяин», а остальные ему сообщают события. Про архитектуру, не про скорость. |

## Бенчмарк

```bash
go test -bench=. -benchmem -run=^$ ./07-race
```

Apple M1 Pro, Go 1.27 (1000×1000 инкрементов на операцию):

| Бенч | ns/op | B/op | allocs/op |
|---|---:|---:|---:|
| `BenchmarkAtomic` |  74 264 039 | 32 522 | 1004 |
| `BenchmarkMutex`  | 165 645 393 | 149 733 | 1369 |
| `BenchmarkChan`   | 665 438 792 | 67 084 | 1295 |

**Вывод:** `atomic ≈ 74 ms` < `mutex ≈ 166 ms` (×2.2) < `chan ≈ 665 ms` (×9).

Для простого счётчика `atomic` быстрее всего — инкремент без блокировки, одной инструкцией CPU. `Mutex` платит за Lock/Unlock, но выигрывает, когда под защитой сложная логика, а не один `++`. Канал — на порядок медленнее из-за передачи сообщений и синхронизации горутин; брать его ради счётчика не стоит, он про модель «share memory by communicating», а не про производительность.
